`th smoo calendar list | events list | show | create | update | rm | respond | find-time | block` — the CLI twin of the hosted MCP `calendar_*` tools (SMOODEV-3764, ADR-147 §2). It runs as you, on your own, org and shared Google / Microsoft 365 / iCloud calendars. Deleting an event, answering an invitation, inviting attendees and changing an event that has guests all confirm first (`--yes` / `--dry-run`).
