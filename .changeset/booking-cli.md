`th booking` — CLI for the org's Google-Calendar booking page. `config get/set` (merge-updates availability: timezone, days, hours via HH:MM or minutes, durations, buffer, min-notice, window, calendar + conflict calendars, display name), `slots` (open times rendered in the config timezone), `bookings` (list), `block add/list/rm` (manual busy time), `calendars list/connect/rm` (Calendly-style multiple Google account connections — connect prints the Google OAuth URL to authorize a blocking calendar), and `link` (public booking URL). Available as both `th booking …` and `th api booking …`.
