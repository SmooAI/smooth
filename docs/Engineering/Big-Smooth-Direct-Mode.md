# Big Smooth — Direct vs Sandboxed mode (retired)

> **Retired 2026-07 (pearl th-7b0bed).** This page documented the choice between `th up` (sandboxed microVM) and `th up direct` (host daemon). PR #124 (pearl th-f4a801) removed the microVM sandbox stack entirely, so there is no choice left to document: `th up` boots Big Smooth on the host and dispatches the operative as a host subprocess with in-process Narc surveillance. See [[../Decisions/ADR-004-remove-microvm-sandbox-stack]] for the decision, [[../Operations/Running-Locally]] for how to run it, and git history for the full original content of this page (including the direct-vs-sandboxed bench comparison table).
