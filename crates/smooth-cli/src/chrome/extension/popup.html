Trusted input: …
Trusted input uses Chrome's debugger: real clicks and keystrokes (for sites that ignore scripted ones), answering alert/confirm dialogs, screenshots without switching tabs, console and network logs, file uploads and running JavaScript. Chrome shows a "started debugging" bar while it is in use.
